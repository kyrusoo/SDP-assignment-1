# Assignment 1: Builder Pattern - Smart Home System

This repository contains the Java 17+ implementation of a Smart Lock configuration module applying the **Builder Design Pattern**.

## Features
* Immutable `SmartLock` product class.
* Fluent `SmartLockBuilder` with domain-oriented methods.
* Single-field and cross-field domain validations.
* `SmartLockDirector` managing `SAFE` preset configurations.
* Automated unit testing suite covering valid, invalid, boundary, and reuse scenarios.
